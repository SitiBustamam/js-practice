# js-practice

My JavaScript learning repo. I'm working through
[freeCodeCamp](https://www.freecodecamp.org/) and using this space to practice
writing and running code on my own machine.

## Files

- `practice.js` — a scratchpad covering variables, functions, arrays, loops, and objects.

## Running the code

```bash
node practice.js
```

## Notes to self

- `node <filename>` runs a JavaScript file.
- `console.log(...)` prints something to the terminal.
- Save the file before running, or you'll run the old version.
